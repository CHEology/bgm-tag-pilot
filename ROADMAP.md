# Roadmap

## v0.1

- Single subject / collection editor tag suggestion panel.
- Local DOM detection.
- Delayed collection editor detection after the user opens Bangumi's edit UI.
- Preview-only rule suggestions.
- Manual insertion into the existing tag input.
- No automatic save or collection update behavior.

## v0.2

- User settings.
- Rule toggles.
- Local settings persistence.
- Visible rule explanations.

## v0.3

- Current collection page scan.
- Preview-only suggestions across visible items.
- No batch apply.
- Exportable scan summary.

## v0.4

- Optional small-scale batch apply.
- Backup before any mutation.
- Strong confirmation flow.
- Narrow item limits.
- Clear recovery guidance.

## v0.5

- Tag normalization.
- Alias management.
- User-managed tag mappings.
- Duplicate and variant detection.
